SmartTeX options

Configure where SmartTeX enhances your LaTeX editor.

Define domains where SmartTeX should be active. Enter one hostname or URL per line. Wildcard subdomains are supported; for example, *.example.org includes the main domain and its subdomains. URL paths and trailing slashes are ignored. Lines beginning with # are ignored.

Features

Choose which SmartTeX previews should appear in document editors.

Reference and citation popups

Choose whether previews for \ref, \eqref, and citation commands open on hover in the editor and Live preview, or only beside the source editor cursor while it is inside the command.

Choose whether source previews open while the text cursor is inside an equation, table, or figure, or when the corresponding source is hovered.

Autocomplete

Choose how labels are ordered in SmartTeX autocomplete lists for commands such as \ref and \eqref.

Source highlighting

Each source annotation can be disabled and assigned its own color. Highlights are rendered behind editor text and editor controls.

Live previews

This experimental button switches the compiled-PDF pane to a fully rendered SmartTeX document preview. It is hidden by default. Popup previews for equations, tables, and figures remain available independently.

Depending on the popup-trigger setting, move the text cursor into or hover over an inline or display equation to show a live KaTeX preview beside it. SmartTeX applies \newcommand, \renewcommand, and \providecommand definitions found earlier in the active LaTeX file. Moving into a tabular, tabularx, longtable, or array block shows a live table preview with its rules, alignment, formatted text, and inline mathematics. Moving into a figure block shows its project image or PDF together with its caption.

Changes are saved automatically.
